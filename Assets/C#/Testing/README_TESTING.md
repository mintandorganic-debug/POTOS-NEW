# Тестовая сцена

## Создание
1. Скопировать папку `Assets` из архива поверх проекта, дождаться компиляции.
2. `Tools -> Testing -> Create Test Scene`
   (копирует GameplayScene в `Assets/Scenes/TestScene.unity`, добавляет объект `TestHarness`,
   регистрирует сетевые префабы, добавляет сцену в Build Settings).
3. Открыть `TestScene` и нажать Play. Хост запускается сам. `F1` - панель, `F2` - пауза.

Другие пункты меню: `Tools -> Testing -> Open Test Scene`, `Open Log Folder`.

## Панель (F1)
- Session: хост / подключение по IP, боты (Passive / Random / Smart), Start / Reset match,
  скорость игры, таймеры, настройки ИИ, режим CHAOS.
- Manual: любое действие от лица любого игрока (карта, цель, отмена, защита, кража,
  конец хода, смена типа карты, смена фазы, эффекты, аксессуары, монеты и фишки).
- Auto: автотест на высокой скорости.
- Sound: все звуки персонажа (idle, реакции, ATK, AFTERMATH).
- Log: живой лог с фильтрами, поиском, копированием и сохранением.

## Боты
- Passive - манекен, пропускает свой ход. Нужен, чтобы было кого атаковать.
- Random - без интеллекта, случайные допустимые действия.
- Smart - защищается всегда, выбирает цель с наибольшим числом аксессуаров.
- CHAOS: боты пробуют НЕДОПУСТИМЫЕ действия. Если сервер принял такое действие,
  в логе появляется ERROR "CHAOS: illegal action ACCEPTED".

## Автотест
Сценарии: для каждой атакующей карты - попадание или кража (успех / таймаут), отмена
(до цели / после цели / по таймауту), защита каждой защитной картой. Затем добираются пары
мест (атакующий -> жертва). После каждого сценария проверяется: игра не зависла, ход
сменился ровно один раз, карты потрачены или вернулись, аксессуары сохранились,
Unity-ошибок не было. Отчет: `autotest_*.txt` рядом с логом.

## Логи
`<persistentDataPath>/GameLogs/session_*.log` (кнопка `Open Log Folder`).
Строка: `#id t=игровое_время r=реальное_время f=кадр РОЛЬ Tход КАТЕГОРИЯ сообщение`.
Попадают все события игры, каждое отклоненное действие с причиной, отмены атаки с
методом и строкой кода (`CANCEL SEQUENCE (called from X:123)`), все Unity warning / error /
exception.
