# Карты, анимации и эффекты: что есть в проекте

Таблица собрана автоматически по файлам проекта (ветка `main`) и спецификации заказчика `POTOS_Card_System.xlsx`. «Да» значит, что файл найден по названию. Колонка «Анимации рук» показывает три клипа из файла `props/models/hands.fbx`: подготовка (PREP), действие (ACTION), окончание или отмена (END).

Важно: в игру подключён только один набор анимаций, `COLT` (револьвер: достаёт, стреляет, убирает). Остальные клипы уже лежат внутри игрового `props/models/hands.fbx` (77 клипов), но к аниматору `Player_AC` не подключены. Для конфискации клипы называются `ATK_Gorshok_*` (горшок).

## Как карта связана с анимацией в коде

1. У карты в `CardData` есть строка `actionId`. Сейчас у всех четырёх карт атаки в раздаче стоит `COLT`.
2. `PlayerAnimator` держит список «действие → номер анимации». В префабе `Player` зарегистрировано одно действие: `COLT` → 1.
3. Аниматор `Player_AC` содержит три состояния для номера 1: `Revolver_Prep` (достаёт), `Revolver_Act` (стреляет), `Revolver_Canc` (убирает при отмене). Параметры: `ActionId` (число) и `Attack` (сигнал).
4. Чтобы добавить карту с анимацией, нужно: задать ей свой `actionId`, зарегистрировать его в `PlayerAnimator`, добавить в `Player_AC` три состояния (подготовка, действие, отмена) и подключить клипы из `hands.fbx`. Отмена атаки возвращает руки через состояние `Canc`.

## Чего не хватает

1. Нет клипов рук для карт: Ворон, Обезьяна, Подлость (PSN_MEANNESS), все карты удачи, защиты и крафтовые. У Party Horn, Иммунитета, Рэкета и Богатства есть только действие, у Прослушки нет ничего.
2. Нет картинки (PSD) для карт «Трубка с дротиком» и «Обмен» (PSN_SWAP). В спецификации для карты `PSN_DISABLE_CARD` две разные записи («Инвалидность» и «Переадресация»).
3. Данные карт (`CardData`) есть только для 7 карт из 37; в игровой раздаче участвуют четыре карты атаки (Кольт, Клей, Нож, Паутина).
4. Все четыре играющие карты используют анимацию револьвера (`COLT`), поэтому «клей», «нож» и «паутина» выглядят как выстрел.
