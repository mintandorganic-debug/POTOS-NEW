# Аудит проекта Potos

Дата: 3 ноября 2026. Состояние: ветка `main`, коммит 7928241d (слияние рефакторинга). Аудит составлен по коду, файлам проекта и спецификации `POTOS_Card_System.xlsx`. Пометки: **есть**, **частично**, **нет**.

## 1. Что готово

| Область | Статус | Подробности |
|---|---|---|
| Подключение | есть | Steam-лобби (хост и кнопка Join), подключение по IP. Транспорт выбирается при старте |
| Старт партии | есть | Ожидание загрузки всех игроков, рассадка по местам, выдача аксессуаров (случайно) |
| Очередь ходов | есть | Фазы `Wait, Attack, SelectTarget, Defense, Steal`. Первый игрок случайный |
| Атака | есть | Выбор карты, выбор жертвы, полёт карты по кругу рулетки, защита жертвы, вихрь в дыру, кража монет и аксессуара |
| Таймеры | есть | Выбор цели 10 с, защита 5 с, кража 5 с |
| Эффекты карт | частично | Работают Клей, Нож, Паутина (отличаются от спецификации); у Ножниц есть скрипт без ассета |
| Деньги | есть | Монеты (максимум 30), фишки по номиналам, дождь монет и фишек |
| Рука | есть | Карусель карт с описанием при наведении, подсветка карты |
| Рефакторинг | есть | GameMaster, AttackSequence, PlayerBank, RouletteRotator, MainMenu разбиты на части (см. `RefactoringReport.md`) |
| Журнал | есть | `GameLog` во всех скриптах |

## 2. Раздача и карты

- Данные карт (`CardData`) есть только для 7 из 38 карт. В раздаче участвуют четыре карты атаки: Кольт, Клей, Нож, Паутина.
- Начальные деньги: монет 0, фишек по 4 каждого номинала. По ТЗ каждому нужно 50 фишек.
- Картинки: PSD для 36 карт, PNG для 25. Нет PSD для «Трубка с дротиком» и «Обмен».
- Таблица «карта — анимации — эффекты»: `CardsAndAnimations.md`.

## 3. Анимации (проверено)

- Игровой файл рук `props/models/hands.fbx` содержит **77 клипов**.
- Подключён к аниматору `Player_AC` только один набор: револьвер (`COLT`: достаёт, стреляет, убирает при отмене). Все карты в раздаче играют его.
- **Три клипа (подготовка, действие, окончание) есть у 18 карт**: Паутина, Клетка, Ведро, Дротик, Виски, Шокер, Клей, Нож, Ножницы, Вилка, Огнемёт, Револьвер, Ружьё, Граната, Инвалидность, Обмен, Конфискация (клипы `Gorshok`), Переадресация.
- Частично: Party Horn, Рэкет, Иммунитет, Богатство (только действие), Прослушка (только окончание).
- Нет клипов: Ворон, Обезьяна, Подлость, 4 защиты, 6 карт удачи, 2 крафтовые (15 карт).
- Общие клипы: `HANDS_IDLE*`, `CARD_THROWING`, `CARDS_RECEIVING_REACTION`, `DEALER_BUTTON_NEXT`, `DICE_ROLL`, `SLOT_MACHINE_CALL`.

## 5. Чего в проекте нет совсем

- Игровых фаз «Кости» и «Автомат», логики автомата (модель есть), крафта, победы (1000 фишек и аксессуар), хода дилера первым.
- Ломбарда, барабана аксессуаров, бабочек и панели жертвы.
- Звука: аудиофайлов много, но в игровом коде звук не используется, а лист «19.Звуки» спецификации пуст.

## 6. Не проверено

- В игре: хост Steam, вход по IP, кнопка Join на двух машинах, кража аксессуара, отмена по таймеру, защита (см. `TestChecklist.md`).
- Сборка в Unity после слияния с `main` (добавился чужой `TrailFade.cs`).
- Правка `Interactor`: убран показ информации о карте.
- Подгонка коробки выбора игрока под модель.
- Баг с синими картами на Mac: причина не найдена, предположительно материал `Highlight` (эмиссия 228) на Metal.
